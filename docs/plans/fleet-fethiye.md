## Database changes

One migration, `web/supabase/migrations/2026111xxxxxxx_fleet_fethiye.sql`, generated from `fleet_nausys.json` by a
script (the way `build_catalog_extra.py` did it), applied with `apply_migration`.

### `yachts`: new columns

```sql
alter table public.yachts
  add column name text,                                   -- 'Gusto 7'; null for the old placeholder rows
  add column kind text not null default 'monohull' check (kind in ('monohull', 'catamaran')),
  add column skipper_cabin boolean not null default false,  -- the "+ 1" in "4 + 1 cabins"
  add column extra_berths integer not null default 0,     -- saloon / skipper berths: "8 + 2"
  add column max_guests integer,
  add column water_l integer,
  add column fuel_l integer,
  add column highlights text[] not null default '{}',     -- 'Twin wheels', 'Self-tacking jib', … (English; translated in translations)
  add column gallery jsonb not null default '[]',         -- Shot[] as on courses: {photo_id, shape: 'l'|'p', caption}
  add column layout_photo_id text,
  add column service_pack_eur integer,
  add column deposit_eur integer,
  add column extras jsonb not null default '[]',          -- [{name, note, price_eur, unit: 'day'|'week'|'booking'|'trip'}]
  add column published boolean not null default true;

-- 13.91 m, 7.96 m, 1.25 m need two decimals.
alter table public.yachts
  alter column length_m type numeric(5, 2),
  alter column beam_m type numeric(4, 2),
  alter column draft_m type numeric(4, 2);
```

`model`, `base`, `photo_id` (cover), `description`, `charter_from_eur` and `translations` keep their meaning.
`charter_from_eur` is set from the price list (decision 4) so cards, the prices page and JSON-LD keep working.

### `yacht_prices`: new table, public read

```sql
create table public.yacht_prices (
  yacht_id uuid not null references public.yachts (id) on delete cascade,
  starts_on date not null,
  ends_on date not null check (ends_on >= starts_on),
  week_eur integer not null check (week_eur > 0),
  updated_at timestamptz not null default now(),
  primary key (yacht_id, starts_on)
);
alter table public.yacht_prices enable row level security;
create policy "Anyone can read yacht prices" on public.yacht_prices for select to anon, authenticated using (true);
grant select on public.yacht_prices to anon, authenticated;
-- plus the touch_updated_at and revalidate_site triggers, and a 'yacht_prices' cache tag next to 'yachts' in db.ts
```

72 rows (12 boats × 6 seasons). Season names (Winter … Late autumn) are labels in code, picked by date.

### `yacht_sources`: new table, no read policy

```sql
create table public.yacht_sources (
  yacht_id uuid primary key references public.yachts (id) on delete cascade,
  operator text not null,            -- 'Mercuri International'
  nausys_id bigint not null unique,
  offer_ref text,                    -- 'Offer 77, 11 Nov 2026'
  agent_discount_pct numeric(4, 1),  -- 15
  updated_at timestamptz not null default now()
);
alter table public.yacht_sources enable row level security;  -- no policies: only the service role reads it
```
